# 🌸 Flower Classification Using DenseNet121

A deep learning project for **multi-class flower image classification** using a pretrained **DenseNet121** model.

The model classifies flower images into **14 different categories**.

## 📊 Dataset

* **Number of Classes:** 14
* **Dataset Size:** Approximately 11,000 images
* **Task:** Multi-class image classification
* **Pretrained Model:** DenseNet121

### 🌼 Classes

```python
[
    'astilbe',
    'bellflower',
    'black_eyed_susan',
    'calendula',
    'california_poppy',
    'carnation',
    'common_daisy',
    'coreopsis',
    'dandelion',
    'iris',
    'rose',
    'sunflower',
    'tulip',
    'water_lily'
]
```

## 🧠 Model

**DenseNet121** pretrained on ImageNet was used as the backbone for feature extraction and classification.

The pretrained model was fine-tuned for the 14 flower categories.

## 📈 Results

The model achieved:

> **92% overall accuracy**

across the 14 flower classes.
